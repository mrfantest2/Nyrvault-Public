# Nyrvault Privacy Policy

**Effective date:** 29 September 2026

Nyrvault is an offline single-player game. The current Android release does not use advertising, analytics, crash-reporting SDKs, accounts, social login, cloud synchronization, or background network services.

## Data collection and sharing

Nyrvault does **not collect or transmit personal data to the developer**. It does not request Internet access and does not include code paths for HTTP, WebSocket, analytics, advertising, or telemetry services.

The app stores the following information locally on the device so the game can function:

- game progress, upgrades, resources, relic collection, world/depth state, and progression counters;
- feedback/accessibility preferences such as sound, haptics, reduced flash, and reduced motion;
- bounded local beta diagnostics such as aggregate frame-time counters and sanitized gameplay breadcrumbs.

These local files are not uploaded automatically and are not shared with third parties by Nyrvault.

## Beta diagnostics

The in-game Beta Diagnostics screen is local-only. A diagnostic report can leave the app only when the user explicitly chooses **COPY BETA REPORT**, which copies sanitized report text to the Android clipboard. Nyrvault does not automatically send that report anywhere.

The diagnostic report intentionally excludes stable user or device identifiers, advertising identifiers, IMEI/serial values, account details, email, phone number, IP address, and precise location.

## Permissions

The Android app requests only the **VIBRATE** permission, used for optional gameplay haptic feedback. Haptics can be disabled in the in-game Feedback & Access settings.

## Data retention and deletion

Game data and preferences remain on the device until the app data is cleared or the app is uninstalled. Nyrvault disables Android cloud backup for its app data.

## Children

Nyrvault does not knowingly collect personal information from children or any other users because the app does not collect personal information.

## Changes

If a future version adds online services or changes how data is handled, this policy will be updated before that version is released.

## Contact

Questions about this policy can be directed through the Nyrvault project/support channel published with the store listing.
