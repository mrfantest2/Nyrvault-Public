## Core design sequence

`BREAK -> COLLECT -> UPGRADE -> AUTOMATE -> DISCOVER NEW SYSTEM -> GUARDIAN -> DESCEND -> CORE COLLAPSE -> REPEAT STRONGER`

## Product rule

Major progression should change what the player does, reveal something new, or change how existing systems interact. Progress should not be pure number inflation.

## Visual target

The CP-007 direction is locked and its initial visual systems shipped. CP-010 completes the final authored pixel art target while preserving the live cellular excavation gameplay.

See [docs/VISUAL_TARGET.md](docs/VISUAL_TARGET.md) and [assets/nyrvault-target.svg](assets/nyrvault-target.svg).

## Source policy

This public repository is a showcase mirror. Proprietary runtime source, build scripts, tests, internal handoffs and private development evidence are not published.
